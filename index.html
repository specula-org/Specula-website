Why Specula

From a large codebase to a bug you can act on.

Formal verification is powerful, but creating faithful models and connecting counterexamples back to code takes time. Specula automates that full loop.

Get started

Your first run starts with two commands.

Install Specula from source, configure your coding agent, then point it at a local repository. Python 3.10+, Java 21+, uv, and GitHub CLI are required.

Full setup guide → GitHub issues ↗
$ git clone https://github.com/specula-org/Specula.git
$ cd Specula && uv tool install -e .
$ specula setup
$ specula run mysys --artifact=/path/to/repo

Outputs are written to runs/<run-id>.

Auto mode Linux · macOS · Windows via WSL2
