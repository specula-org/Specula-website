# Specula website

Official website for [Specula](https://github.com/specula-org/Specula), an
open-source workflow for finding and reproducing deep bugs in concurrent and
distributed systems with coding agents and TLA+.

The site is dependency-free and served directly by GitHub Pages from the
repository root. It follows the visitor's system color scheme by default and
stores any manual theme choice locally in the browser.

The permanent community entry is `https://specula.info/slack/`. When the Slack
invitation is renewed or replaced, update its target only in `slack/index.html`.
